# UX 自检功能 · 安装说明（给使用者）

扩展面板里的「自检」tab —— 在真实页面上选中一个元素，点「帮我检测」，结合页面上下文自动生成 UX 问题清单。审查由你本机的 Claude Code 完成，本目录是连接扩展和 Claude 的本地服务。

## 前置条件

1. **Node.js**（`node -v` 能输出版本）。没有 → https://nodejs.org
2. **Claude Code CLI 能用**（终端跑 `claude -p "你好"` 有回应，说明源已配好）。
3. macOS（安装脚本用的是 macOS 的 launchd；其他系统见文末）。

## 一键安装

```bash
bash 安装说明所在目录/install.sh
# 例如：bash ~/Downloads/liaison-patched/ux-audit-bridge/install.sh
```

脚本会自动：探测 node/claude 路径 → 生成开机自启配置 → 启动服务 → 探活。看到 `✓ 安装成功` 即可。

## 用起来

1. `chrome://extensions` → **重新加载**扩展。
2. 任意页面按 `Alt+Shift+D` 启动面板 → 选中一个元素。
3. 切到 **「自检」** tab → 点 **「帮我检测」** → 等 30~90 秒 → 问题清单出现。

## 常见问题

- **点检测报「无法连接本地服务」** → 服务没跑。重跑一次 `install.sh`。
- **报「检测超时」** → claude 响应慢或源异常。终端 `claude -p "你好"` 自查源。
- **端口 8765 被占用** → 换端口装：`PORT=8766 bash install.sh`。⚠️ 换端口后需同步改扩展 `liaison.js` 里两处 `127.0.0.1:8765` 为新端口，并 reload 扩展。
- **卸载自启** → `launchctl unload ~/Library/LaunchAgents/com.uxaudit.bridge.plist`

## 隐私说明

选中元素的 HTML 只发到你**本机**的服务，再由你**本机**的 Claude Code 审查，不经过任何第三方服务器（除了你 Claude Code 自己配置的源）。

## 非 macOS

install.sh 只做了 macOS 的开机自启。Linux/Windows 用户可手动跑服务：
```bash
node server.mjs   # 保持这个进程开着即可
```
